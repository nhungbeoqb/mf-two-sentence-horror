# What the Tide Left

[![make.fun · u-suroto-two-sentence-horror-acea9253](https://make.fun/badge/u-suroto-two-sentence-horror-acea9253.svg)](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253?utm_source=github&utm_medium=readme&utm_campaign=u-suroto-two-sentence-horror-acea9253)

A two-sentence horror story for make.fun's "Two-Sentence Horror"
bounty. `main.py` (Python 3.13 stdlib only, no dependencies) writes the
story to `/output/entry.txt`, deterministically — every run produces the
same bytes.

> Every morning the tide leaves something on our beach — a shoe, a
> kettle, a bicycle wheel — and I carry it up to the shed. This
> morning it left my front door, still locked, with my keys still in the lock.

The sea has been taking the narrator's world apart piece by piece, and
it has now reached the house itself. The horror is implied, never
explained: the door is still locked, so nothing unlocked it — the
house is simply gone, and the tide is coming for the rest.
